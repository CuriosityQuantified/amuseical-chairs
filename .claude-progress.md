# Progress — amusical-chairs (GitHub: CuriosityQuantified/amuseical-chairs)

## Current state (2026-07-25)
- Branch `claude/issue-12-additional-ci-g0p0hr`: **two-stage game phase** (issue #12) + **CI**.
- Engine: `TWO_STAGE` set + `buildStageTwo(key, entries, ctx)` in `server/games.js`; `closeGame` on a two-stage key builds stage 2 and re-enters `minigame` with a fresh token/submissions/deadline (`Room.startStageTwo`), scoring at stage 2's close. Phase payload carries `stage`/`totalStages`. `aggregateGame(key, entries, ctx)` now takes the closing stage's `{clientData, secret}` — readroom ignores it.
- Roster is **12 games**. New: **Caption Battle** (`caption`, social, score, `stages: 2`). Stage 1 = seeded prompt (30-prompt bank, no repeats); stage 2 = anonymized pool, 3 votes per player (`votesForPool` clamps to poolSize−1). Metric = votes received. Self-votes rejected server-side by `playerId`; authorship lives in `g.secret.owners` and is revealed only on the scores screen.
- Degenerate pools defined: <2 usable captions → stage 2 skipped, stage 1 scored (room always reaches `scores`). 2 players works (1 vote each).
- Moderation: `shared/textclean.js` (`cleanEntryText`) — code-point length cap 80, strips Cc/Cf/Co/Cs incl. bidi overrides, collapses newlines/tabs, caps Zalgo mark stacks. Host `host:hide` → `Room.hideEntry` broadcasts `game:data`; hidden entries are voided at aggregation. Host screen shows the pool + vote **progress only** — per-entry tallies stay off the projector (live-scores rule unchanged).
- Client contract extended: `GameClients[key].startStage(stage, root, ctx)` and optional `handle.update(clientData)`; `intro` may be a function of stage.
- Pacing: `gamesPerSession` host knob (K-of-N draw over the seeded shuffle, 0 = all) — a two-stage game costs ~2× a normal slot.
- **CI** (`.github/workflows/ci.yml`): `npm run check` (`scripts/check.mjs`), tests on Node 20/22/24, prod `npm audit`. The checker parses browser modules (nothing else does), rejects bare imports in `public/js`, verifies roster ↔ GameClients ↔ tutorials both ways, verifies two-stage wiring, and rejects `Math.random()` in `server/`+`shared/`. Every rule mutation-tested. `test/smoke.test.js` boots the server and fetches every absolute import in the client modules.
